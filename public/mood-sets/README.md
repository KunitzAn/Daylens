# Картинки системных наборов настроений

Сюда кладутся картинки для наборов настроений, которые идут в комплекте с
приложением (пользователь выбирает набор, но не редактирует его).

## Структура

Папка на набор, внутри — 7 картинок по номеру уровня настроения:

```
public/mood-sets/
  classic/          <- id набора: латиница, строчные, через дефис
    1.png           <- 1 = худшее настроение
    2.png
    3.png
    4.png
    5.png
    6.png
    7.png           <- 7 = лучшее настроение
  pastel/
    1.png
    ...
```

Имя папки становится id набора в коде. Человекочитаемое название набора
(«Классика», «Пастель») задаётся отдельно в `src/lib/moodSets.ts` — в имени
файла его держать неудобно.

## Требования к файлам

- **Квадратные**, 1:1
- Формат зависит от содержимого:
  - **PNG** с прозрачным фоном — для плоских иконок/иллюстраций, ложится на
    светлую «пластилиновую» кнопку
  - **JPEG** (quality ~80) — для фото. PNG без потерь на фото распухает в
    3-5 раз без заметной разницы в качестве при отображении ~48px
- **256×256** достаточно: в интерфейсе они рендерятся ~48px, 256 закрывает
  даже 3x-плотность экрана
- До ~30 КБ на файл (фото на JPEG q80 обычно укладываются в 15-20 КБ)

Если исходники другого размера/формата или не идеально квадратные — не
страшно, приведу к нужному виду через `sips` (так уже делалась maskable-иконка
приложения).

## Про размер бандла

Картинки попадают в Workbox precache (нужно для офлайна), поэтому каждый набор
добавляет ~150-200 КБ к тому, что скачивается при установке PWA. Пока наборов
мало — нормально; если их станет много, precache-ить надо будет только
активный набор, а остальные подгружать по требованию.
